# Manage muscle groups

Create and edit the muscle groups used to organise your workouts.

---

## Muscle groups table

The table shows all existing muscle groups with three columns:

- **Colour**: Click the colour to change it, then save the change with the tick icon.
- **Name**: The muscle group's name.
- **Actions**: Save changes or delete the muscle group.

---

## Add a muscle group

Use the form at the bottom of the page to create a new muscle group.

---

## Delete a muscle group

Deleting a muscle group does not remove its workout logs. Only delete a group if you no longer need it.
